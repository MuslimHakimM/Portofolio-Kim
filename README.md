# Personal Portfolio Website

Website portofolio pribadi yang responsif dan interaktif untuk menampilkan pengalaman kerja, sertifikasi, serta daftar proyek pengembangan aplikasi.

## 🛠️ Tech Stack

- **Frontend Framework:** React (Vite)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons & Animations:** Lucide Icons / Framer Motion

## ✨ Fitur Utama

- **Hero & About Section:** Ringkasan profil profesional dan latar belakang keahlian.
- **Projects Showcase:** Galeri proyek pilihan lengkap dengan gambaran antarmuka dan *tech stack* yang digunakan.
- **Certificates & Achievements:** Dokumentasi lisensi serta sertifikasi resmi.
- **Responsive Design:** Tampilan optimal di perangkat desktop maupun *mobile*.

## 🚀 Cara Menjalankan di Lokal

### Prasyarat
- [Node.js](https://nodejs.org/) (versi 18 ke atas)
- Package Manager (`npm`)
